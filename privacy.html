Privacy policy

Last updated: October 31, 2026

This policy covers "Technologia Uploader", the personal tool that uploads videos to the Technologia HQ YouTube channel.

Who uses it

Only the owner of the Technologia HQ channel. It is not offered to anyone else.

What it accesses

  • Permission to upload videos to the owner's own YouTube channel (YouTube Data API, upload scope).
  • Nothing else. It does not read, collect, store, sell or share any data about viewers or other users.

How access is stored

The owner's login token is stored as an encrypted secret in the owner's private GitHub repository and is used only to upload videos. Access can be removed at any time at myaccount.google.com/permissions.

Data retention and deletion

The tool does not store any YouTube data. The only stored item is the owner's login token. To delete it, the owner revokes access at myaccount.google.com/permissions (Google then invalidates the token) and deletes the secret from the private GitHub repository. Uploaded videos can be deleted at any time in YouTube Studio.

YouTube

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Contact

Through the Technologia HQ YouTube channel.
